# 剧透弹幕AI过滤器

一个运行在 Chrome / Edge 浏览器中的 B 站剧透弹幕过滤扩展，使用 **TypeSafe Jev** 分析弹幕的剧透风险，帮助减少观看时遇到的剧透。

> 考虑到速度和成本问题，AI 只分析弹幕文字，不会读取视频内容，所以可能出现误判。


## 安装

1. 前往 [Releases](https://github.com/F-know/spoiler-barrage-ai-filter/releases)，下载扩展 ZIP 包，并查看对应版本的说明。，不要选择 GitHub 自动生成的源码压缩包。
2. 将 ZIP 解压到固定目录。
3. 打开扩展管理页：Chrome 使用 `chrome://extensions/`，Edge 使用 `edge://extensions/`。
4. 开启“开发者模式”，点击“加载已解压的扩展程序”，选择解压后包含 `manifest.json` 的目录。
5. 打开或刷新 B 站视频页。

安装后请保留该目录。更新扩展文件后，在扩展管理页点击“重新加载”，并刷新 B 站页面。

## 使用方法

1. 在 B 站视频页点击播放器弹幕设置按钮旁的机器人图标，打开插件面板。
2. 进入设置，在“Jev API Key”中填写 API Key。
3. 点击“测试”确认连接正常，再返回主面板点击“开始分析”。测试和分析均会调用第三方 API，费用由服务商收取。
4. 分析完成后，根据观看需要调整屏蔽阈值。开启“自动”后，刷新或切换视频时会自动处理。

## 功能

- 支持 B 站普通视频页和番剧播放页的剧透弹幕分析和屏蔽。
- 支持手动分析和自动模式；自动模式下，分析期间会暂停视频，完成后恢复播放。
- 发送前对弹幕文本去重，减少重复分析；缓存上一次完整分析的视频结果，刷新同一视频可直接复用。
- 支持自定义系统提示词、单次请求弹幕数量、并发数、请求超时和屏蔽后的替换文本。


## 从源码构建

需要 Node.js 20.19+（20.x）或 22.12+。

```sh
npm ci
npm run build
```

构建完成后，按照上面的安装步骤加载 `dist` 目录。

```sh
npm run typecheck  # 类型检查
npm test          # 自动化测试，不调用付费 API
```

Windows 下可运行 `npm run package:extension` 生成发布 ZIP 包，输出位于 `release` 目录。
